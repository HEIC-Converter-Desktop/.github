## 🚀 Overview
HEIC Converter for Windows is a desktop tool that opens Apple's HEIC and HEIF image files and saves them in formats every program understands. In a single workflow it acts as a HEIC to JPG converter, a HEIC to PNG converter, and a HEIC to PDF converter, so photos taken on an iPhone or iPad can be viewed, edited, shared, or printed on any Windows PC. Batch processing lets you drop in an entire folder of pictures and convert them all at once, while quality controls keep the result close to the original.

## ✨ Features
- **HEIC to JPG converter** — turn HEIC photos into universal JPG / JPEG images that open in any viewer, editor, or web upload form.
- **HEIC to PNG converter** — export to lossless PNG when you need a transparent or pixel-perfect copy of the original picture.
- **HEIC to PDF converter** — combine one or many HEIC photos into a single PDF document for sharing, printing, or archiving.
- **Batch conversion** — drag in dozens or hundreds of HEIC files at once and convert them in a single pass without per-file clicks.
- **Quality and metadata control** — choose the output quality, preserve EXIF data (date, camera, location), and keep original filenames or apply a renaming pattern.
